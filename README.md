# IAC33

Aplicación Android modular e independiente.

## Principios de arquitectura

- Proyecto creado desde cero.
- Núcleo estable y módulos desacoplados.
- OTA diseñada desde el inicio.
- Canal seguro GPT ↔ IAC33 mediante control plane, validación y auditoría.
- Sin credenciales sensibles dentro del APK.
- Offline Real como capacidad de primera clase.
- Actualizaciones verificadas y reversibles.
- Cada fase debe tener pruebas verificables antes de continuar.

## Orden de construcción

REPO → ARQUITECTURA → APK BASE → NÚCLEO → UI → DATOS → CONECTIVIDAD → IA → SISMICIDAD → C33 → GPS → BACKEND → GPT↔APP → OTA → SEGURIDAD → PRUEBAS → APK MASTER → ACTUALIZACIONES OTA
